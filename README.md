# Mohamed Ibrahim | Cybersecurity Portfolio

Personal portfolio website for a Cybersecurity Specialist & Penetration Tester.

**Live site:** https://0xviber.github.io

## Tech
Plain HTML, CSS and JavaScript. No build step. Fonts and icons load from Google Fonts and the FontAwesome CDN.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server 8000`.
