- **Objective:** Assess the security posture of an enterprise Angular web portal and its supporting REST APIs.
- **Methodology & Execution:**
  1. **Angular Architecture Review:** Inspected client-side Route Guards (CanActivate) for bypass conditions and analyzed HTTP Interceptors for token leakage in unauthenticated requests.
